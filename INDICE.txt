## 3 FORMAS DE EMPEZAR

### OPCIÓN 1: VER DEMO (30 segundos)
```bash
python test_simple.py
```
✓ Muestra 3 escenarios de evaluación
✓ Genera hallazgos automáticos
✓ Calcula niveles de cumplimiento

### OPCIÓN 2: USAR INTERACTIVAMENTE (5-10 minutos)
```bash
python main.py
```
Menú con opciones:
1. Crear estructura
2. Ingresar roles
3. Evaluar
4. Generar reporte
5. Ver base legal
6. Datos de ejemplo
0. Salir

### OPCIÓN 3: USAR COMO LIBRERÍA (programación)
```python
from modelos import EstructuraOrganica, Rol
from motor_evaluacion import MotorDeEvaluacion

estructura = EstructuraOrganica("Mi Empresa")
rol = Rol("Director de Sistemas", nivel=1)
estructura.agregar_rol(rol)

motor = MotorDeEvaluacion()
cumplimiento, hallazgos = motor.evaluar_estructura(estructura)
```
