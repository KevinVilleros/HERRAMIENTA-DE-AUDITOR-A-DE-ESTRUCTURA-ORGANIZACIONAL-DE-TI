3. Evaluar automáticamente

6. Ver ejemplo pre-cargado

### OPCION 3: PROGRAMACIÓN (Python)
```python
from modelos import EstructuraOrganica, Rol
from motor_evaluacion import MotorDeEvaluacion

estructura = EstructuraOrganica("Mi Empresa")
rol = Rol("Director", nivel=1)
rol.agregar_funcion("Planificacion estrategica")
estructura.agregar_rol(rol)

motor = MotorDeEvaluacion()
cumpl, hallazgos = motor.evaluar_estructura(estructura)
print(f"Cumplimiento: {cumpl}%")
```
